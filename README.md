# Aarya Bhujade - Portfolio

Personal portfolio website built with modern web technologies showcasing projects, interactive animations, and design work.

## 🚀 Tech Stack

- **Framework / Bundler:** [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons & Effects:** Lucide Icons, Canvas Confetti, Custom Particle & Audio Effects

## 🛠️ Setup & Development

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

4. **Preview production build:**
   ```bash
   npm run preview
   ```

5. **Run integrity tests:**
   ```bash
   npm test
   ```
